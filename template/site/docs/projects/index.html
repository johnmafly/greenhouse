Project reference

Projects are Example Seed's only resource. This page describes the record every API call and SDK method returns, the rules a name has to follow and what happens to a project over its life.

The project record

A record has three fields. name is the project's unique name within your account. created_at is the time the registry stored it, in RFC 3339 format and UTC. owner is the account that created it.

Naming rules

A name is 1 to 63 characters of lowercase letters, digits and hyphens, and starts with a letter. Names are case-sensitive only in the sense that uppercase is rejected, so two people typing the same name always reach the same project.

Lifecycle

A project exists from the moment the create call returns 201. Its name is reserved for your account from then on: deleting a project retires the name rather than freeing it, so old links and logs never resolve to a different project.

Limits

An account holds as many projects as its plan allows. Reads and writes share the plan's request rate, and a request over the rate gets status 429 with a retry-after header.
