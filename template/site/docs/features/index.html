Features

Example Seed does one thing: it gives every project a single, stable record that all of your tools can read. These are the parts of that job it handles for you.

Stable names

Names are unique within an account and never reused after deletion. A dashboard link, a CI variable or a log line that carries a project name keeps resolving to the same project for its whole life.

One record shape

Creating a project and reading it return the same JSON object. Clients parse one shape, and a record you stored is byte-for-byte the record you read back.

Validation at the edge

The registry rejects invalid names before anything is written, with an error that names the rule the request broke. Bad data never reaches the store, so every reader can trust what it gets.

Hosted or self-hosted

The hosted registry runs the same open-source code you can run yourself. Moving between them is a change of base URL and API key; the API, the SDK and the record shape stay the same.

Plain HTTP

Everything goes through a small HTTPS API described in an OpenAPI document, so any language with an HTTP client can use Example Seed without the SDK.
