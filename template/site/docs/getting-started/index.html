Getting started

This guide takes you from nothing to a stored project and a successful read. You need an API key from the dashboard and a terminal with curl.

Create an API key

Sign in, open Settings, and create a key with the projects scope. Export it so the commands below can use it:

export SEED_API_KEY=your-key

Create a project

Send the project name in a JSON body. The registry answers with the stored record and status 201:

curl -X POST https://api.example.com/v1/projects \
  -H "authorization: Bearer $SEED_API_KEY" \
  -H "content-type: application/json" \
  -d '{"name": "first-project"}'

Read it back

Read the project by name from any machine that has the key. The response is the same record you received when you created it:

curl https://api.example.com/v1/projects/first-project \
  -H "authorization: Bearer $SEED_API_KEY"

Next steps

Wire the registry into your own services with the integration guide, or use the SDK reference to call it from code instead of the command line.
