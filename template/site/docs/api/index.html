API reference

The Example Seed API is described in spec/openapi.yaml (OpenAPI 3.1), which this page follows. Every request goes to https://api.example.com over HTTPS and carries an API key as a bearer token in the authorization header. Request and response bodies are JSON.

createProject

POST /v1/projects creates a project. The body is a JSON object with a required name string. On success the registry returns status 201 and the stored record.

curl -X POST https://api.example.com/v1/projects \
  -H "authorization: Bearer $SEED_API_KEY" \
  -H "content-type: application/json" \
  -d '{"name": "first-project"}'

getProject

GET /v1/projects/{name} reads one project. The name path parameter is required. On success the registry returns status 200 and the record in the same shape createProject returns.

curl https://api.example.com/v1/projects/first-project \
  -H "authorization: Bearer $SEED_API_KEY"

Errors

Errors use standard HTTP status codes with a JSON body that names the problem: 400 for an invalid name, 401 for a missing or wrong key, 404 for an unknown project, 409 when a name is already taken and 429, with a retry-after header, when the account is over its request rate.
