Configuration

The registry and the SDK read their settings from environment variables, so the same build runs in every environment. Nothing is read from files at runtime.

Client settings

SEED_API_KEY holds the key the SDK sends with every request. SEED_BASE_URL points the SDK at a registry; it defaults to the hosted registry and you set it to your own address when you self-host.

Registry settings

DATABASE_URL is the PostgreSQL connection string the registry stores projects in. PORT is the port the registry listens on. LOG_LEVEL sets how much the registry logs: info by default, debug to include every request.

Naming rules

Names are lowercase letters, digits and hyphens, start with a letter and are at most 63 characters long. The rule is fixed so that a name is valid in every registry and every client.

Changing settings

The registry reads its settings at startup. Change a variable and restart the service; because the registry is stateless, a rolling restart changes settings without downtime.
