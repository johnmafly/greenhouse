FAQ

Do I need the SDK?

No. The API is plain HTTPS and JSON, described in an OpenAPI document. The SDK saves you writing the requests and error handling yourself.

Can I rename a project?

No. Names are permanent so that links and logs keep resolving to the same project. Create a new project with the new name instead.

What happens when a name is taken?

The create call returns status 409 and nothing is written. Pick another name, or read the existing project if it is yours.

Can I move from the hosted registry to my own servers?

Yes. Export your projects, load them into your own registry and change SEED_BASE_URL in your clients. The API and record shape are the same.

Is the registry open source?

Yes. The registry, the SDK and the OpenAPI document are all in the public repository under an open-source license.
