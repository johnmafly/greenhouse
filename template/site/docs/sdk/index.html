SDK reference

The JavaScript SDK wraps the HTTP API in a typed client. It runs in Node.js and in browsers, has no runtime dependencies and maps one method to one API operation.

Client

new SeedClient({ apiKey, baseUrl }) creates a client. apiKey defaults to the SEED_API_KEY environment variable and baseUrl to the hosted registry. One client is safe to share across your whole application.

createProject(name)

Calls POST /v1/projects and resolves to the stored record. It rejects with a SeedError when the name is invalid or already taken.

getProject(name)

Calls GET /v1/projects/{name} and resolves to the record. It rejects with a SeedError whose status is 404 when no project has that name.

SeedError

Every failed call rejects with a SeedError. It carries the HTTP status, a machine-readable code and the registry's message, so your code can branch on the code and show the message to people.

Retries and timeouts

The client retries a request once when the connection drops before a response arrives, and times out after 10 seconds. Both values are options on the constructor.
